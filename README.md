## Coolpoint Private Resort Web Application

#### A web application for a private resort for managing resort reservations. It is built with Laravel and ReactJS combined with Tailwind CSS for faster and efficient frontend development. The web application have multiple users where I created a multi-user authentication system for the customers and admins. The highlights of this project is the reservation process and handling. With proper logic in the reservation process it prevents booking conflicts like double booking. It also has a good UI design to easily handle reservations for the admin.

- Dashboard with real-time updates
- Real-time Notifications
- Room Management
- Reservation handling

### Technologies Used
- Laravel
- ReactJS
- Typescript
- Tailwind CSS
- Pusher
- MySQL
